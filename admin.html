How it works

1. Add classes first (CSE-A, CSE-B etc)
2. Add teachers with name, email and college ID — no password needed
3. Teacher goes to login page → Register as Teacher → enters college ID + email → sets own password
4. Assign subjects — pick course code, class and teacher
5. Same course code can have different teachers for different classes
